# Set up Synthesis

Do these three things in order. Report each one in a single plain sentence, and
change nothing on this computer.

1. **Connection.** Use the Synthesis tool `brand_context_frame`. If it answers,
   say which brand this chat is connected to. If the Synthesis tools are
   missing or ask for a sign-in, tell the person to open the plugin's settings,
   choose the synthesis server, and sign in with their Synthesis account, then
   run this shortcut again. Stop there.

2. **Answer memory.** Say: answers that use Synthesis are saved to your brand's
   memory, so it learns from what you conclude. An admin turns this off for the
   whole brand on the brand's card in Settings, under Brands.

3. **Shortcuts.** Say: you can run a ready-made job by typing one word. Try
   these first, then type / to see the rest:
   - /fees checks for Amazon fees that went up for no reason
   - /stockout warns before a product runs out
   - /whyprofit explains why profit moved this month
   - /reorder drafts a reorder plan
   Then say: any other automation runs with /go and its name, like
   /go win-back list.
