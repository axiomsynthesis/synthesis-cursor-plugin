# Synthesis for Cursor and Grok Bot

Your brand's real numbers, and the method for reading them, inside Cursor and
Grok Bot.

## What it adds

- **A connection to Synthesis.** Every channel your brand sells and advertises
  on, answered from your own data.
- **Skills.** How to read Amazon, ads, retention, money and stock numbers
  without the usual traps.
- **Shortcuts.** Type one word, like /fees or /stockout, to run a ready-made job.
- **/deep.** Specialist helpers answer in parallel, a skeptic pulls every number
  again, then you get one checked answer.

## Setup

Install the plugin, then sign in to the `synthesis` server with your Synthesis
account when asked. Type /setup to check the connection.

Support: https://synthesisintelligence.ai/support
